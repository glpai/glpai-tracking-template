# GLP AI tracking template

A free, editable GLP-1 tracking spreadsheet. The [resource page](https://glpai.github.io/glpai-tracking-template/) shows a fictional example dashboard, a [blank Google Sheets template](https://docs.google.com/spreadsheets/d/10cayH7ytX4a8bbMCIOgEJa3ncLnZTnhqs1YPEseBW2k/copy), a [live demo with fictional data](https://docs.google.com/spreadsheets/d/1BJxqUHHvNQVazXcs5ao7fITwfq9053mdmlJOezsdIqw/edit), and an Excel download.

The workbook has four tabs:

- **Start Here:** dashboard with weight, goal progress, BMI, dose count, check-ins, and charts.
- **Dose Log:** one row per medication dose actually taken.
- **Daily Check-in:** optional food, protein, fiber, water, and symptom notes.
- **Weight Progress:** height, units, personal goal, and dated weight entries.

The Google Sheets link prompts you to make your own blank copy. You can also download [`GLP-AI-tracking-template.xlsx`](assets/GLP-AI-tracking-template.xlsx) for Excel or Numbers.

The screenshot uses fictional entries. The downloadable file contains no personal data or example log entries. BMI is a screening measure, not a diagnosis. The template records what you enter; it does not recommend doses or sync with GLP AI.

For ongoing tracking on a phone, see [GLP AI](https://glpai.app/).
